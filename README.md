# Pretty Killer Hub

One page that links to every Pretty Killer site (not the shop or the countdown): Tickets, Show day info, Tracklist, Photo booth, Guestbook and Leaks. Same Pretty (AM) / Killer (PM) style as the other sites, picked by the clock.

To add, remove or reorder a site, edit `SITES` at the top of the script in `index.html` (`big: true` makes a full-width card).
